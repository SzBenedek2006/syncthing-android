Syncthing for Android packages Syncthing to be easy to use on and integrate well with Android. It provides an Android-native UI over the web-based interface Syncthing has by default. 

What is Syncthing?
Syncthing replaces proprietary sync and cloud services with something open, trustworthy and decentralized.
It's an open-source, free, and privacy-respecting real-time file synchronization program for almost every platform including Linux, macOS and Windows.

Syncthing for Android bundles this program optimized for your device.

KEY HIGHLIGHTS
• 🎨 Material Design 3 UI. (Work in progress).
• 📱 Broad Compatibility: Supports Android versions from 6 to 17.
• 📊 System resource usage graphs.
• 🔋 Customizable run conditions to reduce data and battery usage.
• 🔒 Private & Decentralized: Your data syncs directly between your devices in encrypted channels, and isn't stored in the cloud.

IMPORTANT NOTICES

Storage Permissions
This is a Backup, Restore, and File Management app.
It requires All Files Access (MANAGE_EXTERNAL_STORAGE) to perform automated, non-interactive background file synchronization and directory backups.

Project Status & Affiliation
